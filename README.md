# Метрические книги и ревизии села Кириллово

Записи села Кириллово из метрических книг, ревизских сказок и других источников — в DSL
[verso](https://github.com/verso-genealogy/verso), библиотеки для генеалогических данных Российской империи. Каждый файл
`Кириллово/ГГГГ/*.py` — книга одного года: записи в том виде, как они написаны в источнике, с
дореформенной орфографией.

## Как запустить

Нужны Python 3.14 и, лучше, [uv](https://docs.astral.sh/uv/).

```bash
make bootstrap   # .venv и verso v0.1.41
make check       # линтер DSL и выгрузка записей в JSON (records/)
```

Линтер (`make lint`) проверяет записи на противоречия: даты, возрасты, родство. Известные находки
перечислены в `dsllint_baseline.tsv`. `make records` пишет записи в JSON records-v1 —
с ним можно работать без Python-кода DSL.

## reviewed=False

Запись с `reviewed=False` прочитана со скана, но ещё не сверена со сканом владельцем. В ней может
быть ошибка чтения имени или даты — проверяйте по источнику.

## Ошибки и правки

Репозиторий выгружается из рабочего репозитория владельца; последняя выгрузка — в `SYNC.toml`.
Правки (pull requests) сюда не принимаются: следующая выгрузка их перезапишет. Нашли ошибку —
напишите в issues, с номером записи и листом.
